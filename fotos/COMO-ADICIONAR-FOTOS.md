# Como colocar fotos na galeria do site

1. Abra esta pasta `fotos` no GitHub.
2. Clique em **Add file → Upload files** e envie as fotos.
3. Os nomes precisam ser números em sequência: `1.jpg`, `2.jpg`, `3.jpg`... (também vale `.jpeg`, `.png` ou `.webp`).
4. Clique em **Commit changes**. Em cerca de um minuto as fotos aparecem no site, na seção "Galeria".

Dicas:
- A ordem dos números é a ordem no site. A foto `1` aparece maior, e a cada 5 fotos uma ganha destaque.
- Não pule números: se faltarem 3 seguidos, o site para de procurar.
- Fotos de até uns 2 MB carregam rápido no celular.
- Para trocar uma foto, envie outra com o mesmo nome.
